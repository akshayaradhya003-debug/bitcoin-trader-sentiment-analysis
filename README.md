# Bitcoin Trader Sentiment Analysis

## Overview
This project analyzes how Bitcoin market sentiment (Fear vs Greed) affects trader behavior and performance.

## Dataset
1. Fear & Greed Index dataset
2. Historical trader transaction dataset

## Methodology
- Data cleaning and preparation
- Sentiment alignment with trading data
- Behavioral and performance analysis
- Trader segmentation

## How to Run

Install required packages:

pip install pandas numpy matplotlib seaborn streamlit scikit-learn

Run notebook:

jupyter notebook sentiment_analysis.ipynb

Run dashboard:

python -m streamlit run dashboard.py
